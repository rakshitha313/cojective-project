# Cojective Technical Assessment - Website Developer

A modern, high-performance, and responsive landing page built for the Cojective Website Developer Technical Assessment. This project faithfully reproduces the provided Figma design using vanilla web technologies, complete with rich UI micro-interactions, custom video controls, smooth-scroll animations, and dynamic responsiveness.

## 🛠️ Tech Stack & Tools

- **HTML5:** Semantic markup structure.
- **CSS3:** Custom CSS variables, Flexbox, CSS Grid, animations, and media queries for mobile responsiveness.
- **JavaScript (ES6+):** Video player state control, dynamic time tracking, accessibility tweaks, and smooth scroll behavior.
- **Google Fonts & Typography:** Integration of modern sans-serif and monospace typography (`DM Mono`).

---

## ✨ Key Features & Enhancements

1. **Pixel-Accurate UI Design:** Recreated sections based strictly on Figma specifications, including layout, colors, typography, and spacing.
2. **Custom Video Player:** Integrated hero video background with custom playback controls (Play/Pause, scrub bar, duration display, and speed toggle).
3. **Responsive Grid Layouts:** Multi-column grid structures for Product Showcase, Applications, and Statistics that scale down seamlessly for tablet and mobile devices.
4. **Interactive Micro-Interactions:** Smooth hover states, subtle card lift effects, and animated buttons across all sections.
5. **Footer & Navigation:** Fully structured footer links, brand styling, and header navigation bar.
